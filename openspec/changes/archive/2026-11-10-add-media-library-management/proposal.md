# Proposal

## Why

当前项目只有文件浏览、重命名与裁剪工具，媒体库入口仍是占位页。用户每次都要重新输入磁盘路径，无法把「哪些目录属于同一批媒体」保存下来，也无法区分作品集式整理与 Jellyfin 式文件规范。

本变更先建立媒体库的「定义与管理」层，并同时提供两项高风险操作的安全保障：删除作品集媒体库时永久删除其内容，修改媒体根路径时自动迁移作品集目录。扫描、索引、播放和作品集实体留到后续变更，避免在数据模型尚未稳定时过早耦合扫描器。

## What Changes

- 使用本机 SQLite 数据库持久化媒体根路径、媒体库、来源、删除密码与迁移任务；**不再使用 `config.json`**。
- 新增媒体根路径设置与校验；有作品集媒体库时修改根路径 SHALL 触发自动迁移；只有文件规范媒体库时直接保存新路径，不移动文件。
- 新增媒体库 CRUD（创建、列表、编辑、移除），每个媒体库包含名称、组织形式、可选类型与路径信息。
- 组织形式固定为两种：
  - `collection`（作品集）：一个媒体库对应媒体根路径下的一个系统托管目录；目录名对用户不可见，用户只管理显示名称。
  - `convention`（文件规范）：一个媒体库可配置多个来源目录，兼容 Jellyfin 的目录组织与命名约定；不复制、不移动来源文件。
- 媒体库类型为可选补充信息（电影 / 电视剧 / 图片），仅用于展示与提示，**不约束**目录内容，也不做文件过滤。
- 新增全局删除保护密码：
  - 移除作品集媒体库时，验证密码后递归删除其目录内容，再删除数据库记录。
  - 移除文件规范媒体库时，只删除数据库记录与来源记录，不删除任何来源文件，不要求密码。
  - 媒体根路径迁移会删除旧副本，因此同样要求密码。
- 新增媒体根路径自动迁移：后台任务复制作品集目录到新根路径，切换数据库后自动清理旧副本；失败时保留旧根路径与旧数据。
- 新增媒体库页面（替换占位页），提供空状态、媒体根路径设置、媒体库卡片、创建/编辑对话框、删除确认、迁移进度与路径选择。
- 在设置对话框中增加「媒体」与「安全」区块，可修改媒体根路径、查看数据库位置、设置/修改删除保护密码。
- 作品集仅作为「组织形式」概念引入：本次**不创建作品集实体**，不建立作品集与媒体库的多对多关系。
- 明确根路径扫描范围：只有媒体根路径下已登记的 collection 媒体库属于该根路径的扫描范围；未登记子目录与文件规范来源不在此范围。

明确不在本次范围内：

- 不扫描目录、不建立媒体索引、不提取元数据、不生成封面。
- 不播放视频、不集成 Jellyfin/Emby 服务端 API。
- 不实现作品集实体、合集分组或跨媒体库聚合。
- 不提供文件规范媒体库的来源目录删除；来源始终由用户或其他媒体服务器管理。
- 不实现多实例并发访问同一个 SQLite 数据库。

## Capabilities

### New Capabilities

- `media-library`: 媒体库的定义、配置与生命周期管理。覆盖 SQLite 持久化、媒体根路径与自动迁移、组织形式（作品集 / 文件规范）、可选类型、隐藏的作品集目录、多来源路径、删除保护密码、状态展示与安全边界。

### Modified Capabilities

无。本次不改变文件浏览、重命名或视频裁剪的既有行为。

## Impact

- **共享包** `packages/core`：新增媒体库类型、组织形式/类型枚举、名称与目录段校验、默认目录名生成与状态类型；保持纯函数、无 I/O。
- **后端** `apps/server`：
  - 新增 `better-sqlite3` 与 `@types/better-sqlite3`，并在根 `package.json` 的 `pnpm.onlyBuiltDependencies` 中允许其构建。
  - 新增 SQLite 模块：默认 `~/.gallery/gallery.db`，支持 `GALLERY_DB` 覆盖；启用 WAL、外键与 schema 版本。
  - 新增媒体库、设置、密码与迁移任务的数据访问层。
  - 新增 `/api/library/*` 路由，注册到 `app.ts`。
  - 新增作品集目录创建/接管、递归删除、迁移任务与启动恢复。
  - 复用现有 `resolveUserPath`、`isInside` 与符号链接校验，禁止路径穿越。
- **前端** `apps/web`：
  - `/library` 由占位页替换为媒体库管理页；`lib/nav.ts` 移除「规划中」标记。
  - 新增 `features/library` 组件与 API 客户端方法；新增可复用的目录选择对话框（基于现有 `/api/fs/roots`、`/api/fs/list`）。
  - 设置对话框新增媒体根路径、迁移进度、删除保护密码与数据库位置。
- **数据**：新增用户级 SQLite 数据库 `~/.gallery/gallery.db`，不写入仓库；仓库 `data/` 仍只用于缩略图、临时文件等可重建缓存。
- **文档**：`README.md` 功能清单增加「媒体库管理」，运行时数据说明增加数据库位置；`AGENTS.md` 接口概览增加 `/api/library`。
- **安全**：媒体库目录与来源路径仅在服务端解析；删除与迁移要求密码；变更类请求继续要求 `x-gallery-client: 1`；拒绝符号链接与越界路径。
